Deadlight Outpost — a 3D zombie survival game in the browser. Defend the outpost through 10 waves of the horde: WASD to move, mouse to aim, click to shoot, R to reload, Shift to sprint. Three.js, fully offline, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play.
